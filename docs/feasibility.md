# 可行性报告

## 结论

链路可行。能达到「上完课按一下录音键，之后全自动」的程度，不需要电脑常开，不需要付费软件。

代价是两件东西：**手机装 1 个同步工具**、**注册 1 个免费云端仓库**。这两样是「零手动」的物理前提，绕不过去——Android 上没有任何系统原生能力能定时把本地文件送出去。

---

## 逐段判定

| 环节 | 可行性 | 载体 | 说明 |
|---|---|---|---|
| 录音 | 确定可行 | 手机自带录音机 | 你本来就要做的事，不算额外操作 |
| 文件出手机 | 可行，需 1 个工具 | FolderSync → WebDAV 网盘 | 系统原生做不到，必须装一个能后台监听的 App |
| 定时调度 | 确定可行 | GitHub Actions | 免费、常驻、与电脑无关 |
| 转写 | 可行 | Whisper（本地推理） | 免费；精度中上，低于专业商用 ASR |
| 作业抽取 | 部分可行 | 规则引擎 + 可选 LLM | 见下方「精度预期」 |
| 截止日换算 | 确定可行 | 纯代码 | 中文相对时间规则明确，准确率高 |
| 推送提醒 | 确定可行 | 飞书机器人 | 手机通知栏弹出，App 不在前台也能收 |
| 日历提醒 | **不完全可行** | .ics 订阅 | 多数 Android 日历对订阅日历不执行闹钟，只显示不响。所以只做可视化 |
| 作业看板 | 确定可行 | GitHub Pages | 静态页面，可加到主屏幕 |

## 成本核算

| 项目 | 用量 | 是否免费 |
|---|---|---|
| GitHub Actions | 每 30 分钟一次，空跑约 30 秒/次 ≈ 24 分钟/月；加上 Whisper 转写，每月约 100–400 分钟 | 私有仓库 2000 分钟/月免费额度内；公开仓库无限 |
| GitHub Pages | 静态托管 | 免费 |
| Whisper | 本地 CPU 推理 | 免费（消耗的是 Actions 额度，不是钱） |
| 飞书机器人 | 自建群自定义机器人 | 免费 |
| 网盘 | 只存最近录音，可设 7 天清理 | 免费版够用 |

**结论：零现金成本。** 唯一的"钱"是 Actions 的运行额度。

## 精度预期

必须诚实说清楚：**没有样本就没有准确率**。以下是基于设计的定性判断，不是实测数字。

| 任务 | 预期 | 依据 |
|---|---|---|
| 转写字符准确率 | 80–90% | Whisper small 中文课堂场景，远场与术语是弱项 |
| 「这段在不在布置作业」召回 | 较高 | 关键词预筛覆盖常见表达，宁多不漏 |
| 「作业标题」可读性 | 较好 | 规则清洗引导语，保留原句主干 |
| 「截止日期」准确率 | **较高** | 不依赖模型，纯规则换算；算不出就不给日期 |
| 误报 | 中等 | 派给班委的任务会被过滤，但「老师随口提的事」仍可能被当成作业 |

**验证方法**（这是唯一负责任的做法）：
录 3 节课，人工写出标准答案，跑一遍，把抽取结果和标准答案逐条对比。跑完才知道真实水平，再决定要不要开 LLM 增强或换更高精度 ASR。

## 已知限制与降级路径

### 1. 转写精度不够
- **降级 A**：把 `WHISPER_MODEL` 从 `small` 提到 `medium`，精度升一档，耗时约 2 倍
- **降级 B**：`TRANSCRIBE_ENGINE=custom`，接任意更高精度的 ASR（写个脚本读 `{input}` 写 `{output}` 即可，不动本项目代码）
- **降级 C**：开 LLM 增强，让模型做一次领域纠错（同音错、术语错）

### 2. 手机后台把同步工具杀了
- 表现：网盘里迟迟没有新音频
- 处理：按 `setup-android.md` 的保活三件套逐条设置（电池无限制、自启动、任务加锁）
- 这是 Android 生态的固有问题，任何方案都要面对，不是本方案的缺陷

### 3. 时间解析失败
- 表现：作业进了「日期待确认」分组
- 处理：这是**刻意设计**。老师说的话本身可能含糊（"下次课交"），猜一个日期去提醒比不提醒更糟

### 4. GitHub Actions 停摆
- 免费仓库若 60 天无提交，定时任务会自动暂停
- 处理：点一次手动 Run workflow 即可恢复；或让任意一次提交唤醒

### 5. 隐私
- 录音会上传到你的网盘，再被云端任务下载转写
- 音频只在你自己的私有仓库与私有网盘之间流转，不入第三方库
- 若不接受：把 `SOURCE` 改回 `folder`，在本机跑，牺牲"不依赖电脑"

## 不可行的边界（明确说清）

- **100% 零搭建**：不存在。市面没有「课堂录音 → 自动作业提醒」的成品，这个组合没人做。
- **手机端不装任何东西就零手动**：不存在。Android 原生没有定时读目录并上传的能力。
- **日历订阅一定会响**：不成立。多数国产 Android 日历对订阅日历不执行闹钟。**所以提醒的可靠性压在上推送，不在日历。**
- **抽取 100% 准确**：不成立。任何 ASR + 抽取都有误报漏报，只能做到「漏了能补救、错了能看出」。
